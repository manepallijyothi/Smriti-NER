   # 🧠 Smriti-NER — DementiaCare Digital Twin

> **An AI-powered Digital Twin for personalized cognitive monitoring and dementia care**

Smriti-NER is a healthcare-focused Digital Twin prototype designed to support people experiencing cognitive decline and help caregivers monitor changes in cognitive and behavioral patterns over time.

Instead of treating every individual with the same baseline, Smriti-NER creates a **personalized digital representation of an individual's cognitive state** and continuously updates it using cognitive performance and daily behavioral data.

---

## 🎯 Problem Statement

Dementia and cognitive decline can gradually affect memory, attention, daily activities, mood, and overall independence.

Traditional assessments are often performed at specific intervals, which may not capture small day-to-day changes in a person's cognitive and behavioral condition.

There is a need for a system that can:

* Continuously monitor cognitive performance
* Establish an individual's personal baseline
* Detect changes from that baseline
* Provide personalized cognitive activities
* Help caregivers understand long-term trends
* Support early monitoring and intervention

---

## 💡 Our Solution

Smriti-NER creates a **Digital Twin of the user's cognitive and behavioral state**.

The system collects information from cognitive activities and daily inputs, analyzes the data, compares the current state with the individual's historical baseline, and updates the Digital Twin.

### Core Flow

```text
Real Person
     ↓
Cognitive & Daily Data
     ↓
Data Processing
     ↓
Personal Digital Twin
     ↓
Trend & Change Detection
     ↓
Personalized Recommendations
     ↓
Twin Updated with New Data
```

The Digital Twin evolves as new information becomes available.

---

# 🧬 What is the Digital Twin?

A Digital Twin is a digital representation of a real-world entity that changes according to new data.

In Smriti-NER, the real-world entity is the **person's cognitive and behavioral state**.

The Digital Twin represents:

* 🧠 Memory performance
* 🎯 Attention
* ⚡ Reaction performance
* 😴 Sleep patterns
* 🚶 Activity levels
* 😊 Mood
* 💊 Medication adherence
* 📈 Cognitive trends

The system compares the current measurements with the user's personal baseline rather than relying only on a fixed population-level threshold.

# 📱 Prototype Workflow

### Step 1 — Create Profile

The user/caregiver creates a profile.

### Step 2 — Establish Baseline

The system collects initial cognitive performance data.

Example:

```text
Memory       82
Attention    78
Reaction     1.8 sec
Activity     70%
Sleep        7 hrs
```

This becomes the individual's initial baseline.

### Step 3 — Perform Cognitive Activities

The user completes cognitive games and assessments.

### Step 4 — Update Digital Twin

New results are added to the Digital Twin.

### Step 5 — Analyze Changes

The system compares current performance against historical patterns.

### Step 6 — Generate Insights

Example:

```text
Memory performance ↓ 18%
Activity level      ↓ 22%
Sleep duration      ↓ 1.5 hrs
```

### Step 7 — Personalize

The system recommends suitable cognitive activities and monitoring actions.

# ⚕️ Medical Disclaimer

Smriti-NER is a **proof-of-concept research and monitoring platform**.
